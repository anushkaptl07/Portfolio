CoFound

A role-based job matching platform connecting companies with student job-seekers.

02 — MACHINE LEARNING

UPI Shield

An end-to-end UPI fraud detection system with real-time risk assessment.

  • Built and evaluated an XGBoost fraud classification model with leakage auditing, feature ablation and threshold tuning — achieving 99.05% accuracy, 95.27% fraud recall and a 97.19% F1-score.
  • Removed deterministic/leaky behavioral features to build a more realistic model, validated through robustness testing and feature-importance analysis (99.84% ROC-AUC).
  • Built a FastAPI prediction service returning fraud probability, risk level and transaction decision (Approve/Block/Investigate), connected to a responsive HTML/CSS/JS dashboard.
